# Security Policy

## Scope

Course Materials Assistant is designed to process course files locally. It does not upload course materials, call an external API, execute Access macros, or modify source databases as part of its normal scripts.

## Sensitive Data

Do not commit API keys, passwords, tokens, private keys, real course materials, student identifiers, or generated `.course-assistant` data. Extracted JSON includes local file paths, so review it before sharing.

## Reporting a Vulnerability

Do not publish credentials or private course files in an issue. Report security problems privately through the repository's configured security contact or GitHub private vulnerability reporting. Include the affected version, reproduction steps, and the smallest safe example that demonstrates the issue.
